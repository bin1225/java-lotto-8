# java-lotto-precourse

--- 

## 기능 목록

---

### 입력

- 구매 금액을 입력받는다.
- 당첨 번호 6개를 쉼표(,)로 구분해 입력받는다.
- 보너스 번호 1개를 입력받는다.

### 출력

- 발행된 로또 번호를 출력한다.
- 당첨 통계를 출력한다.
  (각 등수별 당첨 개수 및 수익률)


### 도메인

- 로또를 발행한다.
    - 번호는 1~45 범위 내의 서로 다른 숫자 6개
- 로또 구입 금액(1장당 1,000원)에 따라 여러 장의 로또를 발행한다.
- 당첨 번호를 기준으로 각 로또의 결과를 판단한다.
- 등수별 상금을 기준으로 최종 통계를 계산한다.
    - 1등: 6개 일치 → 2,000,000,000원
    - 2등: 5개 + 보너스 일치 → 30,000,000원
    - 3등: 5개 일치 → 1,500,000원
    - 4등: 4개 일치 → 50,000원
    - 5등: 3개 일치 → 5,000원

### 예외 처리

### 1. 구입 금액

- 1,000원 단위가 아닌 경우
- 숫자가 아닌 값을 입력한 경우
- 숫자 타입의 표현 범위를 초과한 경우

### 2. 당첨 번호

- 쉼표(`,`)로 구분했을 때 6개가 아닌 경우
- 각 번호가 1~45 범위 내 정수가 아닌 경우

### 3. 보너스 번호

- 1~45 범위 내 정수가 아닌 경우
- 보너스 번호 입력 시 불필요한 문자가 포함된 경우
- 당첨 번호와 중복되는 경우
